# 自动保存，写回统一为无 BOM 的 UTF-8

玻璃没有任何保存控件，"零保存操作"是核心体验，因此保存全自动：停止输入约半秒写盘、失焦立即写盘；绑定文件被外部修改且本地无未保存改动时自动重载。读取自动识别 UTF-8（含 BOM）/UTF-16/GBK，但写回一律为无 BOM 的 UTF-8——GBK 原文件在首次编辑后会被永久转码，数据上不可逆。我们接受这个不可逆：统一编码换来跨设备一致的行为，且 GBK 本就无法表达部分字符；需要保留 GBK 的文件不应使用本工具编辑。

## Considered Options

- 保留原编码写回：需要维护每个文件的编码状态机；GBK 仍有无法表达字符导致丢失的风险
- 手动 Ctrl+S 保存：与"界面上一颗按钮都没有"的设计冲突
