## 一、背景

v1.2.0 将玻璃窗口从 WinForms 迁移到 WPF（AllowsTransparency 逐像素透明），
目的是让玻璃不透明度与文字不透明度彻底独立。迁移后实测发现四个功能回归：

| # | 功能 | 症状 |
|---|------|------|
| 1 | 打字输入 | 输入内容直接卡死 |
| 2 | 鼠标中键滚动 | 完全不可用 |
| 3 | Ctrl+滚轮缩放 | 完全不可用 |
| 4 | 贴边拉伸 | 完全不可用 |

根因：WPF 的输入管线（键盘焦点路由、TSF 输入法、鼠标捕获）与 WinForms 差异极大，
四个功能各自需要针对 WPF 的深度适配，修复周期不可控且互相纠缠。

---

## 二、决策

**回滚到 WinForms 架构（v1.1.x 基线），在此基础上用「双层窗口」重新实现
玻璃不透明度与文字不透明度的彻底独立。**

### 为什么选这条路线

| 对比维度 | 方案 A（回滚 + 双层窗口） | 继续 WPF 调试 |
|----------|--------------------------|---------------|
| 已验证功能 | 全部可用 | 四个同时坏，互相纠缠 |
| 独立性实现 | 双层窗口（纯 GDI，可控） | 逐像素透明（已实现但引入新问题） |
| 修复周期 | 底色层窗口约 80 行新代码 | 每个功能都需要 WPF 管线适配 |
| 中文输入法 | 原生 EDIT 控件完整 IME 支持 | WPF TSF 集成待验证 |
| 风险 | 低（技术全部已验证） | 高（WPF 输入管线不可控） |

## 三、双层窗口原理

### 现状问题（单窗口统一透明度）

```
桌面 D → 玻璃窗口（统一透明度 g）→ 用户看到
背景像素: g·G + (1-g)·D
文字像素: g·C + (1-g)·D     ← 文字跟着变透明
```

### 双层窗口方案

```
桌面 D
  ↓
底色层（半透明窗口，透明度 = G_a）: G_a·G + (1-G_a)·D
  ↓
编辑层（不透明窗口，背景 = 底色层透出的颜色）: 文字像素 = T_a·C + (1-T_a)·底色
```

- 玻璃不透明度（G_a）：只作用于底色层
- 文字不透明度（T_a）：只作用于文字，通过文字颜色向玻璃色混合实现
- 两者完全独立，互不影响

### 编辑层的透明背景实现

编辑窗口使用 `TransparencyKey = 玻璃色`：
- 玻璃色像素 → 完全透明 → 透出底色层
- 文字像素（非玻璃色）→ 不透明渲染
- 点击落在透明像素时穿透到底色层窗口 → 底色层转发给编辑层文本框

## 四、回滚与实现步骤

### 4.1 回滚

```
git checkout v1.1.0 -- GlassForm.cs Program.cs
```

恢复 v1.1.0（commit `fcceb3a`）时的以下文件：
- `GlassForm.cs` — WinForms 玻璃窗体（含 EM_SCROLL 滚轮、顶部拖动区、贴边缩放）
- `Program.cs` — WinForms 主循环

保留 v1.2.0 已有的：
- `Config.cs` — 新增字段（TextOpacityPercent、ZoomPercent、MiddleScrollMode、WheelLinesPerNotch）
- `SettingsForm.cs` — 设置页新增行
- `GlassWindow.cs` — 删除（WPF 版本弃用，代码保留在 wpf-experiment 分支）
- `Overlays.cs` — ZoomBadge 保留（改由 WinForms 版调用）

### 4.2 新增底色层窗口

新建 `GlassBackdrop.cs`：
- 无边框、置顶、ShowInTaskbar=false、鼠标穿透（WS_EX_TRANSPARENT）
- BackColor = 玻璃色，Opacity = 玻璃不透明度
- 尺寸/位置与编辑层实时同步（LocationChanged/SizeChanged 联动）
- 最小化/隐藏/关闭联动

### 4.3 编辑层改造

`GlassForm.cs` 恢复后叠加以下改动：
- `Opacity` 固定为 1.0（编辑层自身不透明）
- `TransparencyKey = 玻璃色`（玻璃色像素透出底色层）
- `TransparencyKey` 跟随 `ApplyAppearance` 中的玻璃色实时更新

### 4.4 需移植的 v1.2.0 功能

| 功能 | 来源 | 改动 |
|------|------|------|
| 中键滚动三档模式 | 0b1094b | 逻辑不变，改在 WinForms 事件中处理 |
| 滚轮每格行数 1–10 | 0b1094b | EM_SCROLL 循环（WinForms 原生） |
| Ctrl+滚轮缩放 | 67d01e4 | 逻辑不变 |

## 六、风险与缓解

| 风险 | 缓解 |
|------|------|
| 底色层与编辑层拖动时出现错位 | LocationChanged 同步 + SetWindowPos 联动 |
| 透明像素的鼠标穿透导致点击落空 | 底色层接收并转发给编辑层文本框 |
| 中文输入法在透明像素区域候选框位置偏移 | IME 候选框跟随光标而非窗口，影响有限 |
| ClearType 在混合透明层上渲染质量 | 文字不透明度默认 100%，混合比例极端时才有感知 |
